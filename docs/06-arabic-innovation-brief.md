# موجز الابتكار (بالعربية)

**المشروع:** نقطة الصحة — نموذج تجريبي لحلقة متابعة مرضى السكري (بيانات اصطناعية).

**الفجوة التشغيلية المراد اختبارها (فرضية غير مثبتة):** قد تصل قراءات المتابعة المنزلية إلى الفريق دون وضوح من يملك الخطوة التالية ودون أثر موثق لإغلاق الحلقة، وقد يصعب على الطبيب معرفة سبب أولوية مريض ما أو مدى موثوقية بياناته.

**ما يقدمه النموذج:**
١. واجهة للمريض (جوال أولاً): ماذا أرسل؟ هل استلم الفريق؟ ما المهمة التي تنتظر ردي؟
٢. قائمة مراجعة للطبيب (حاسوب أولاً): من يحتاج مراجعة، ولماذا، وحداثة البيانات واكتمالها، والمسؤول، وما لم يُحسم.
٣. محرك قواعد حتمي وشفاف يفصل بين: جودة البيانات، واكتمالها، ومحفزات المراجعة، وإلحاح سير العمل — دون درجة خطورة مخترعة. العتبات توضيحية وتحتاج تحققاً سريرياً.
٤. مسار متابعة صريح: جديدة ← إقرار ← متابعة معيّنة ← بانتظار الرد ← إعادة تقييم ← إغلاق، مع مالك للمهمة، ورسائل يعتمدها الطبيب، وإعادة فتح عند معلومة جديدة، وسجل أحداث كامل.
٥. مقاييس تشغيلية تُحسب من سجل الأحداث مع البسط والمقام.

**حدود واضحة:** ليس نظام فرز أو تنبؤ أو ذكاءً اصطناعياً؛ لا يعدّل دواءً أو علاجاً؛ البيانات اصطناعية ولا تُعد دليل فعالية؛ سرعة الإقرار لا تثبت نتائج سريرية أفضل.

**المطلوب للتحقق:** مراجعة سريرية للقواعد، تقييم قابلية استخدام مع مقارنة بقائمة زمنية بسيطة، مراجعة الحوكمة والأمن، ثم دراسة تكامل.

**الخطوة العملية التالية:** جلسة مراجعة مع ٣–٥ أطباء وممرضين على السيناريوهات التسعة.
